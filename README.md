# Building Suit monorepo

This directory currently contains the reviewed migration plan and agent instructions. The applications have **not** been copied or restructured, and no database migration has been executed.

- [Complete migration plan](PLAN.md)
- [Ongoing development rules for agents](AGENTS.md)
- [Ongoing development workflows for agents](docs/agent-workflows.md)
- [Source review evidence](docs/source-audit.json)

Implementation is limited to the work packages and completion criteria in the plan. Existing product roadmaps are reference material, not additional work automatically included in this migration.

Agent guidance describes how to work in the target monorepo. Its paths, commands and conventions must be reviewed against the finished implementation before completion. One-time migration instructions belong in the migration plan and runbooks, not in the permanent agent rules or workflows.
