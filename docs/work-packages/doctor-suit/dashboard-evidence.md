Shared templates own every visual element; Doctor adapters own source queries, date windows, counts, permissions, selection and navigation. The catalogue describes the new optional presentation. Each eligible verified context needs both dashboard and appointment read grants. A doctor sees every authorized clinic; a shared secretary sees only the exact eligible clinic/capability pairs across practices. Every source request remains authorized by the existing server appointment RPC; patient names additionally require patient read authority. Clinic options come from the authenticated server context RPC, never user metadata or inferred ownership.

Today means the local calendar day in each clinic's current verified timezone, calculated from one captured instant. Appointment totals include all statuses; the active queue includes all dates. The existing SQL RPC counts the full scoped population and independently bounds each appointment/queue page to twenty. No metric derives from the displayed row count, combines incompatible local days, invents revenue or clinical outcomes, or uses fallback sample results. The synthetic administrative boundary remains visible.

The controller bounds parallel reads to four and applies results only when the entire authorized population succeeds. Generation/abort and identity checks discard obsolete work. Known denial clears every section and aborts siblings; location/timezone revision mismatch fails closed. Foreground/periodic and explicit refresh revalidate authority. A change to any context invalidates multi-clinic data even when the selected independent clinic is retained. Context selection reloads the overview; unmount cancels pending work and trailing refreshes.

Source actions capture full scope plus identity, day and independent page positions. They revalidate context, explicitly choose the exact permitted clinic, then resolve the record from a fresh authorized source page. Forged/mismatched IDs, clinic/practice, dates and page parameters are denied. Current record details are separate from loading full history: a current appointment can remain readable while an older clinic in its history is unavailable. No history count or empty result is fabricated before requesting it. Full history still requires every represented clinic grant and known denial disposes private state.
