## Population and clock definitions

`doctor_operational_report` uses one materialized source cohort for counts, status partitions, current-assignee workload and the selected20-row source page. It reports one explicitly selected authorized clinic and an inclusive pair of clinic-local dates, converted to a half-open UTC interval ending at the following local midnight. The bound is93 local dates; DST days naturally contain23 or25 hours. Every response carries timezone, location version, exact UTC bounds and its database observation instant. UI date/context changes abort old reads and discard previous counts.

Appointments enter by current starts_at, with booked/checked_in/in_progress/completed/cancelled/no_show partitioned separately. A reschedule changes one source row and moves it out of its old window; historical events are not additional appointments. Follow-up enters by due_at and current assigned/in_progress/completed/cancelled state; this is a due-window current-state report, not a claim about work completed during that interval. Open workload is current assigned/in_progress work grouped once by current assignee, with blocked-open counts separate. Reassignment never counts both old and new assignees.

Messages, fulfillment records and import previews enter by created_at. Queued/claimed/sent/delivered/failed/unknown messages remain distinct synthetic states; none contributes to completed appointments or follow-up. Operational received documents do not imply clinical review. Validated import previews do not imply canonical imported records. No patient names, contact destinations, bodies, clinical text, source payloads or credentials enter report rows. Rows carry exact source IDs, current version, state, timestamp and current assignee for source reconciliation.

Appointments, worklists and patient-administrative populations check their current grants independently. Missing grants produce unavailable/null populations and no source identifiers, never fabricated zeros. Doctor/secretary identities and clinics remain independent. No-grant/foreign-practice/archived-clinic/ambient-service access is denied. The existing complete BsReportsPage is reused; no shared presentation behavior changes. Export is unavailable: each page is a fresh authoritative request snapshot, not a frozen multi-page export. A concurrent change between page requests can alter subsequent pages, so totals/source reconciliation must use the returned observation times and refresh rather than assume historical pagination.
