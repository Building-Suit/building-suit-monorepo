Debug APK/device verification is proposed first, with no store upload, signing purchase or external distribution. Proposed API29/API36 smoke coverage does not replace an approved physical-device matrix. A Keystore-backed session bridge needs explicit security review; no localStorage/Preferences credential copy is accepted. Exact build commands in the structured packet are proposals, not registered/executed commands.
