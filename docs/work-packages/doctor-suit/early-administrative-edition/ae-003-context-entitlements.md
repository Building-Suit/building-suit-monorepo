# DOS-AE-003 owner-bound context entitlements

Authorized context reads return a minimal per-practice entitlement: computed state, account revision, current write/allocation flags, over-limit state and a server-observed expiry boundary. The practice’s stored owner determines the subscription; an independently subscribed actor cannot fund it. Prices, subscriber identifiers, approval references and private period evidence are omitted. Stored role grants remain distinct from subscription availability so history and security reductions remain possible. Candidate responses require valid metadata; legacy preview fixtures remain compatible.

Scope/cache identities include revision, computed state, allowance flags and expiry. A clock-based state change therefore invalidates old work even without a database revision. Ordinary refresh observation timestamps refresh deadlines without clearing drafts. Browser-only monotonic timers subtract request elapsed time, chunk long delays, clear captured work/drafts/channels before refreshing at expiry, and never restore access from a local clock or failed network read. Account, tenant, edition and role invalidation remain in force.
