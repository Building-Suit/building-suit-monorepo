## Local source and configuration

The source is the local Insync-synchronized folder named `building-suit-brain`. Its discovered personal absolute path is configured only through the app's ignored `.env` using private server variable `NUXT_HQ_BRAIN_PATH`. The committed `.env.example` leaves the value empty and explains setup. Do not copy a personal path into documentation, source, public runtime configuration, artifacts or logs. The scene can remain visible without the setting; missing, unavailable or ineligible local folder configuration produces an unavailable Brain state.

This is local-mirror access rather than a direct Google Drive API connection. Insync owns synchronization independently. A `connected` result means the server could open and scan the local folder, not that it authenticated to Google Drive or proved current cloud synchronization. Note `modifiedAt` values come from local file modification times; `observedAt` records when the server read the mirror. Neither proves that the latest cloud edits have arrived.

## Local read boundary

The two GET routes require an actual loopback socket peer, an allowed loopback Host and the `X-HQ-Brain` request header. Browser fetch-site, Origin and Referer values are checked against the local origin when supplied. Forwarded host/IP headers are not an authority source. Responses use private no-store headers and generic error messages. These are local access guards, not an identity or remote-access system.

The configured folder must be absolute, be named `building-suit-brain`, be a directory and not be a symlink. Traversal remains inside its resolved root, skips symlinks and indexes eligible `.md` files. Hidden entries, script directories and secret/private-key-like path names are excluded. This is name-based filtering rather than classification of every otherwise eligible note's contents. Selected notes are re-resolved and rechecked for root containment, file identity and bounded reads; the client supplies an opaque indexed ID rather than a filesystem path.

The implementation caps the index at 2,000 notes, depth at 20, inspected entries at 20,000 and each Markdown file at 512 KiB. It marks truncated, oversized or unavailable traversal results as partial. Local relative paths are returned; absolute host paths and detailed filesystem errors are not. There are no write routes or cloud credentials.
