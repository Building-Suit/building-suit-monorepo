# Public repository research adapter — source-only scope

The meeting system includes a separate anonymous GitHub read adapter at `apps/company-hq/server/meetings/publicRepositoryResearch.mjs`. Constructing the adapter performs no request. It is not wired to a route, selected by an environment variable or admitted by the current synthetic-only worker. Its distinct `public-read-only` mode is deliberately rejected with `live-provider-not-qualified`.

The adapter requires an explicitly scoped research task: budget zero, `public-repository-read` action, `github-public-read` tool, one exact `https://github.com/OWNER/REPO` URL and a timeout from one to 120 seconds. A future activation must select this exact public-read scope, its worker identity and participant authorization independently of meeting attendance. No model, speech, personal subscription credentials or API key is used.

If separately authorized and invoked, it constructs at most five anonymous GET requests to the fixed `api.github.com` host: repository metadata, README, license, root package.json and the latest commit. It never follows repository-provided download URLs, redirects or arbitrary shared targets. Input rejects subpaths, credentials, query strings, explicit ports, IP literals and other hosts. Responses are limited to 256 KiB each and 512 KiB total, with a 64 KiB result limit. Deadline and caller cancellation apply to fetch and response reads. No downloaded code or package script is executed.

The structured report distinguishes observed metadata, quoted untrusted documentation, inference and unknowns. It covers declared capabilities, license evidence, maintenance dates/counts, root dependencies, provider mentions, operating-cost unknowns, data-handling declarations and use-case fit. README claims do not prove runtime behavior, privacy, model entitlement, compatibility, security, legal clearance or zero-cost operation. Common secret forms are redacted from retained prose; the adapter does not fetch credential files or accept credentials.

`apps/company-hq/tests/unit/meetings-research.test.mjs` uses only mocked fetch and synthetic repositories. It checks fixed-host requests, permission and budget gates, private-target rejection, malicious README treatment, secret redaction, inaccessible/rate-limited sources, missing files, redirects, cancellation, timeout and byte bounds. These tests establish local adapter behavior; they do not verify live GitHub allowance, network access, repository content, provider entitlement, cloud capacity or staff qualification. No live network request, worker activation or hosted change is part of this evidence.
