# سجل القرارات والاعتماد

محدث: 2026-09-19. عدم الرد ليس موافقة. هذه الأسئلة إحالات إلى [أسئلة المحاسب §٩](ACCOUNTANT_REVIEW_AR.md#٩-أسئلة-الاعتماد)، وليست مواصفة بديلة. كل قرار `PROPOSED` أدناه بلا معتمد أو تاريخ اعتماد أو دليل موافقة حتى وصول رد صريح.

| المعرف / الحالة | السياسة المقترحة وأسبابها | النطاق والمهمة المحجوبة | صاحب الاعتماد والدليل المطلوب / السؤال غير المحسوم |
|---|---|---|---|

| AS-D02 / PROPOSED | فصل تجميعي/ترحيل/مراقبة وطبيعة/رصيد/عرض، مع خريطة تاريخية تحفظ حركات الآباء | AS-S2-01 وAS-S2-02؛ ق٠٢، ق٠٣، ق٠٧، ق٠٨ | المحاسب والمؤسس؛ أسئلة ٣، ٤، ١٢: الشجرة والتصنيف المؤرخ ومنع الترحيل وحدود المراقبة؟ |

| AS-D04 / PROPOSED | جرد مستمر ومتوسط متحرك ومنع السالب حسب ملاءمة النشاط؛ ليست سياسة معتمدة | AS-S5-01؛ ق١٤–ق١٦؛ يبدأ التصميم في AS-S1-02 | المحاسب والمؤسس؛ سؤال ٧: التكلفة والمرتجعات والحركات السابقة والدفعات؟ |

| AS-D07 / PROPOSED | نافذة واحدة تتنقل داخليًا بين القيد والحساب وتعيد السياق؛ النموذج اصطناعي للقراءة | قبول AS-S1-01 ثم تركيب إنتاجي في AS-S3-01 | المؤسس والمحاسب؛ سؤال ١٣: قبول التكوين والألفاظ والرجوع قبل إدخاله إلى الإنتاج؟ |

أسئلة ٦، ٨، ١٠ و١٢ تبقى مفتوحة للذمم والأصول والعملات والتقارير؛ لا تُمحى لمجرد عدم تنفيذها الآن. مخاطر التصنيف التاريخي والدقة والأرشفة والحصص والتزامن والاستعادة في الخطة §١٢ باقية.
