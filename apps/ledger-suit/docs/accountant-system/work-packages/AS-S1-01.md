# AS-S1-01 — دليل الأرقام ونموذج رحلة المراجعة

الحالة: `READY_FOR_REVIEW`؛ المرحلة ١ من الخطة §١٠؛ اليومية §٦ والقبول §١ و§٣. كُتبت خطة الحزمة قبل تعديل الكود، 2026-09-19.

## النتيجة وحدودها

اختبار حتمي لكل قيد وأرصدة ومجاميع المثال، ونموذج قراءة قابل للتشغيل: اليومية ← القيد ← حساب بمعرفه ← حركاته الاصطناعية ← نفس القيد ← نفس اليومية. النموذج لا يستخدم بيانات حقيقية أو صلاحيات إنتاج ولا يدّعي تشغيل الوحدات غير المكتملة.

داخل النطاق: وثائق الاستئناف والقرارات والتتبع؛ fixture بالوحدات الصغرى وBigInt مستقل عن حسابات الإنتاج؛ test fixture Nuxt مع طبقة UI الحالية؛ حالات تحميل/خطأ/إعادة محاولة/غير موجود/رفض؛ حفظ الفلاتر والتاريخ والترتيب والصفحة والتمرير والتركيز وملاحظة مراجعة غير محفوظة؛ عزل بيانات العرض عند تبديل منشأة/جلسة/حساب.

خارج النطاق: تعديل الحسابات المستوردة أو دلالات الترحيل/العكس/الموافقة؛ حساب تقارير إنتاج؛ SQL أو تغيير تاريخ ترحيلات؛ مخزون أو ذمم أو إقفال؛ تركيب النموذج في إنتاج؛ دمج أو نشر أو تجهيز موارد.

الاعتماديات: pnpm 10.33.0 وNode كما في .node-version؛ root lockfile؛ Chromium للاختبارات. اختبار النموذج والأرقام بلا backend. اختبارات الانحدار المالي تحتاج Ledger المحلي 60321 وقاعدة 60322 موثقة الملكية والتاريخ، ولا يُعاد ضبط قاعدة تخص عملًا آخر.

لا يحتاج هذا الدليل توقيع سياسة. قبول التكوين وانتقال المراحل ينتظر AS-D01–AS-D07. لا يوجد قبول محاسب مسجل في الوثائق الحالية.
