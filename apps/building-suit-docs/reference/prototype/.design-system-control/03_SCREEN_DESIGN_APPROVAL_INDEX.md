# Cowork Screen Design and Approval Index

**Status:** Auth flow converted to a Vue/Vite prototype (2026-06-23). Login, registration, verification, password recovery/reset, and One Last Step now share the same componentized auth surface in `prototype/src/App.js` and `prototype/src/components/`.

The repository provides system rules rather than product-screen designs. The screen families and their sources are planned in `05_PROTOTYPE_SOURCE_MAP.md`; their required states in `06_SCREEN_STATE_CATALOGUE.md`. Cowork designs each composition in a later Build Prototype Screen task and records it here before it becomes a baseline. **Plan-approved ≠ composition-approved:** each row still requires user approval of the actual designed screen.
