## Catalogue rules

- Record observable evidence, not assumptions.
- Canonical JSON controls exact token values.
- Every reusable component must appear as a shared Vue prototype component before reuse on a product screen.
- Every approved state must map to both prototype fixtures and a proposed Flutter state/widget contract.
- Vue component names above point to the current prototype implementation in `prototype/src/components/`. Flutter widget names remain non-binding naming suggestions for the later Flutter build.
- The framework migration intentionally removed the old Pug component lab. Future product screens must reuse the Vue components, tokens, primitives, and states in the current app rather than reintroducing one-off markup.
