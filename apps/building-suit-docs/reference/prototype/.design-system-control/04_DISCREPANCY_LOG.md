## Classifications

- **System mismatch:** implementation differs from an approved design-system rule or component treatment.
- **Token conflict:** a visual value differs from canonical JSON.
- **Behavior conflict:** visual evidence implies behavior not approved by UX/PRD.
- **Missing evidence:** a required design-system mode, component state, asset, or rule is absent from the approved handoff.
- **Screen design decision:** UX defines the requirement but Cowork needs a user-approved composition decision.
- **Implementation interpretation:** visual intent is approved but requires a documented web/Flutter translation.
- **Human decision:** sources cannot resolve the conflict.

Never close a discrepancy by silently changing a normative source.
