# Presentation Style Guide

> **Status:** Complete (initial). Brand direction for slide decks — especially the investor deck. Source of truth: `01-strategy/`, `02-logo-system/`, `03-visual-identity/01_COLOR_SYSTEM.md` + `02_TYPOGRAPHY_SYSTEM.md` + `04_LAYOUT_AND_SPACING.md`. Premium, structured, one idea per slide.

---

## Investor deck style
- **Format:** 16:9 (1920 × 1080). Consistent master layouts; generous margins (≈64–80px); 12-column grid.
- **Look:** premium and calm — navy and light slides alternating, **one gold accent per slide**, lots of negative space.
- **Principle:** one message per slide; headline states the takeaway; visuals support, don't crowd.
- **Footer:** small logo + slide number + confidentiality note, consistent across slides.
- **Bilingual:** provide English and Arabic (RTL) versions if needed; keep "Building Suit" in Latin.

## Slide cover style
- **Background:** Building Navy → Deep Structure Navy gradient with subtle window-grid motif + faint gold glow.
- **Logo:** light/silver logo (or 3D building-B) with clear space.
- **Title:** deck title in Manrope ExtraBold (Headline/Mega scale), Pearl White, optional one gold accent word.
- **Sub:** one line (tagline or context) + date/round; muted Sky Steel.
- Premium and uncluttered — this sets the tone.

## Problem slide style
- **Goal:** make the pain vivid and clear.
- **Layout:** strong headline (the problem in one line) + 2–4 supporting points or a simple visual (chaotic chat/paper/cash imagery, muted).
- **Color:** light or navy slide; use **Signal Red / Amber** sparingly to signal pain points (not gold).
- Keep it honest and concrete (group chats, lost receipts, disputed dues, one-person dependency).

## Solution slide style
- **Goal:** Building Suit as the calm, transparent answer.
- **Layout:** headline ("One transparent system for the whole building") + product visual (phone mockup) + 3 key value points.
- **Color:** navy or light; **gold accent** on the key value or the product; positive, premium tone.
- Mirror the problem slide structure so the contrast is obvious.

## Product slide style
- **Goal:** show the product clearly.
- **Layout:** phone mockup(s) + short feature callouts (icon + label + one line) using the brand icon style.
- **Color:** navy/light surface; one gold accent (e.g. the highlighted feature); real on-brand screens.
- Don't crowd with many screens; 1–3 focused mockups per slide.

## Financial / metrics slide style
- **Goal:** credibility through clear data (note: market/forecast figures are planning assumptions, label them as such).
- **Layout:** one headline metric large (Display/ExtraBold) + supporting chart/table; minimal chrome.
- **Color:** navy/light; **gold to highlight the single key number/series**; semantic colors only for true positive/negative.
- Label axes/units; round sensibly; cite sources; keep it honest and uncluttered.

## Typography rules
| Element | Font | Size (16:9) | Weight |
|---|---|---|---|
| Slide title / takeaway | Manrope | 32–40 pt | Bold/ExtraBold |
| Big metric / statement | Manrope | 60–96 pt | ExtraBold |
| Subhead | Manrope | 20–24 pt | SemiBold |
| Body / bullets | Manrope | 16–20 pt | Regular/Medium |
| Caption / source | Manrope | 11–13 pt | Medium |
| Arabic | IBM Plex Sans Arabic | match | as above |

- One takeaway-style headline per slide; 2–3 weights; left-aligned (LTR) / right-aligned (RTL).
- Avoid dense paragraphs and tiny text; no caps/tracking on Arabic.

## Chart color rules
- **Primary series:** Building Navy `#16293B`; **highlight series / key data point:** Premium Gold `#D89B42`.
- **Secondary series:** Slate Blue `#36506E`, Sky Steel `#7E97B3`, Cloud Gray `#CBD2DB` (a navy-blue ramp).
- **Semantic** colors only for genuine positive/negative (Verified Green / Signal Red) — not decoration.
- Limit to ~3–4 series; gold marks the one thing to notice.
- Minimal gridlines, clear labels/units, no 3D chart effects or heavy shadows; consistent style across the deck.

## Icon rules
- Use the **brand icon style** (flat, 2px outline, rounded — see `03-visual-identity/05_ICONOGRAPHY_STYLE.md`).
- Neutral icons by default; **gold only for the one emphasized icon** per slide.
- Consistent size and stroke across the deck; pair icons with short labels.
- Don't mix icon styles or use clip-art.

---

## Visual hierarchy
1. **One takeaway per slide** — the headline says it.
2. **One focal point** — usually the gold-accented element or the key metric.
3. Size + weight + color for hierarchy; generous whitespace.
4. Consistent master layouts, grid, and footer across all slides.
5. Gold is precious — one accent per slide; semantic colors only for real data.
6. Premium = restraint: fewer elements, more space, sharp contrast.
