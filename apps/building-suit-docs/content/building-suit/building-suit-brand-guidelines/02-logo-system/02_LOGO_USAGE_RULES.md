# Logo Usage Rules

> **Status:** Complete (initial). The rules governing correct use of the approved Building Suit logo. See `01_LOGO_ANALYSIS.md` for the analysis and `assets/logos/logo-source-notes.md` for source files.

> **Variant reminder** — the filename describes the logo's own colour:
> - `assets/logos/building-suit-logo-dark.png` — **navy / dark** logo → use on **light** backgrounds.
> - `assets/logos/building-suit-logo-light.png` — **white / silver** logo → use on **dark** backgrounds.
> Both share identical geometry and the same gold windows/door.

---

## Primary logo usage
The primary logo is the **3D building-shaped "B"** in its approved form. Always use the supplied master files — never recreate, redraw, or approximate the mark.

- Choose the variant that gives the **strongest contrast** with the background (see tables below).
- Keep the full mark intact: building façade, windows, door, and lettered bowls.
- Maintain the original proportions and 3D rendering at all times.
- Respect the clear space defined in `03_LOGO_CLEAR_SPACE.md`.

## Logo on gold backgrounds
Gold is the brand's **accent**, not a primary logo background — use it rarely and carefully.

- **Preferred:** avoid placing the logo on a flood-gold background; the gold windows lose their meaning and contrast against gold.
- **If gold must be used:** use the **dark (navy) logo** on gold for strong contrast.
- **Never** use the light (white/silver) logo on gold — low contrast and the gold windows disappear.
- Treat gold backgrounds as special-occasion only (premium print, limited marketing). Default to navy, white, or silver surfaces instead.

| Gold background | Allowed variant | Verdict |
|---|---|---|
| Solid brand gold | Dark (navy) logo only | Acceptable with caution |
| Gold + the light logo | — | ❌ Not allowed (low contrast) |

## Minimum sizes
To keep the building details (windows, door) legible, do not reproduce the full logo below these sizes. For smaller contexts use a simplified/app-icon form (see `05_APP_ICON_GUIDE.md`).

| Context | Minimum size | Notes |
|---|---|---|
| Digital (full logo) | **40 px** tall | Below this, window detail muddies |
| Digital (comfortable) | 64 px tall and up | Recommended for clarity |
| Print (full logo) | **12 mm** tall | Below this, detail is lost on most print |
| Print (comfortable) | 18 mm tall and up | Recommended |
| Favicon / very small UI | Use the **app-icon mark**, not the full logo | See app-icon guide |

> Because the current masters are **raster (PNG, 920 × 1245 px)**, avoid enlarging beyond their native resolution. A vector master is required for large-format print (see source notes).

## Digital usage
- Use PNG masters with transparent backgrounds; never re-export from a screenshot or compressed copy.
- Maintain aspect ratio (height-driven sizing is simplest given the tall mark).
- Respect minimum digital size (40 px tall) and clear space.
- Pick the variant by background contrast, supporting both light and dark UI themes.
- Do not apply filters, blends, or effects (see `04_LOGO_DOS_AND_DONTS.md`).

## Print usage
- Use the **dark (navy) logo** on light stock; the **light (white/silver) logo** on dark stock.
- Respect minimum print size (12 mm tall) and clear space.
- Request a **vector (SVG/PDF)** master for any sizeable print; do not upscale the raster PNG.
- For single-colour print (one-colour stamps, embossing), use the dedicated flat/mono companion mark once produced (currently an outstanding asset) — do not attempt to flatten the 3D logo manually.
- Confirm gold reproduces correctly with the printer; pin exact gold values from the colour system.

## Mobile app usage
- **App icon:** follow `05_APP_ICON_GUIDE.md` — do not drop the full tall logo into the icon slot.
- **In-app brand placements** (splash, headers, about screen): use the variant matching the theme — light logo in dark mode, dark logo in light mode.
- Keep clear space even in compact headers; if space is tight, reduce size rather than crop.
- Provide @1x/@2x/@3x raster exports (or vector) so the mark stays crisp across densities.

## Website usage
- **Header/nav:** size the logo to ~32–48 px tall; switch variant with light/dark themes.
- **Footer:** the light logo on the dark footer (or dark logo on a light footer) with full clear space.
- **Hero:** the 3D logo can appear larger as a brand moment; keep it on a calm area with strong contrast.
- **Favicon:** use the app-icon mark, not the full logo (see app-icon guide).
- Serve appropriately sized assets (and a vector where possible) for retina displays; never CSS-stretch the logo.
